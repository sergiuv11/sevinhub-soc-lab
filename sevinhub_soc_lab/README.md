# SevinHub SOC Lab

A local web platform combining an Autonomous SOC Analyst Agent, Incident Response Simulator, and Global Cyber Threat Map for interactive SOC training and investigation.

## Getting Started

1.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
2.  **Run the application:**
    ```bash
    python main.py
    ```
3.  **Access in browser:** Open `http://localhost:8000`

## Features

- **SOC Analyst Agent:** Analyze URLs, domains, IPs, email text, and logs.
- **Incident Response Simulator:** Practice incident response with realistic scenarios.
- **Global Cyber Threat Map:** Visualize simulated cyber attacks.
- **Interactive Dashboard:** Monitor threat levels, SOC score, active incidents, and attack charts.
- **Case History:** Store and review investigation results.
- **Reporting:** Export investigation reports.
